## How to read a graha entry

Each graha carries, in fixed order:

1. **Identity block** — nature, texture, gender, varna, guna, dhatu, direction, day, gem,
   metal, color, taste, season, dignity map, aspects. Pure data: this is what the rule
   engine reads. **Dignity map feeds STRENGTH-01 and NBR-01 c1 — if it's not here, those
   rules cannot run.**
2. **Good characteristics** (well-placed / well-signified) — bullet bank for prose.
3. **Bad characteristics** (afflicted / paapa expression) — bullet bank. **This list is
   FUNC-01's "harmful natural traits" source.** Per FUNC-01: for a *functional benefic*,
   these traits are suppressed (style only, not events); for a *functional malefic*,
   they manifest as event texture.
4. **Generic karakatvas — 200 numbered items**, grouped by category. Numbered so any
   correction can cite "Sun #47" precisely.
5. **Question-specific karakatvas** — what THIS graha signifies when the question belongs
   to a given kelvigal domain (career / money / health / marriage / foreign). This is the
   layer that makes GATE-01 verdicts *precise*: the same Mars means different things in C8
   (friction energy) vs H4 (the blade) vs R2 (courage to defy).
6. **Kelvigal card mapping** — the exact card IDs from `foundations/kelvigal.md` where this
   graha is a named *kelvikkana kaaraka graham*.
7. **Worked example** — this graha's instance in the sample chart (Thulam lagna, female,
   1992-03-02, Dindigul), run through the locked rules.

**Conventions**: rasis given English (Tamil). Orbs/dignity per classical table. Node
exaltation/debilitation debates are **commentary only, never scored** (locked decision H).

# ☀️ 1. SUN (Surya / Sooriyan)

## Identity block
- **Natural nature**: Malefic-textured (krura — hot, dry, scorching), sattvic in quality.
  Not paapa in the Saturn/Mars sense; his harm is burning, not blocking.
- **Texture / pace**: Kingly, fixed, daily-rhythmic. Rises on time, never hurries, never
  waits. Authority without aggression. Results arrive on schedule, like sunrise.
- Gender: male · Varna: Kshatriya · Guna: sattva · Dhatu: asthi (bone)
- Direction: East · Day: Sunday · Season: greeshma (summer) · Taste: bitter
- Gem: ruby · Metal: gold / copper · Color: copper-red / orange
- **Dignity map**: own Simmam (Leo) · exalted Mesham 10° (Aries) · debilitated Thulam 10°
  (Libra) · moolatrikona Simmam 0–20°
- **Aspects**: 7th only (full)
- Friends: Moon, Mars, Jupiter · Enemy: Venus, Saturn · Neutral: Mercury

- Decisiveness

## Bad characteristics (afflicted) — FUNC-01 harmful-trait source
